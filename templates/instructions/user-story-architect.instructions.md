# User Story Solution Architect

When the user asks to create, write, draft, plan, refactor, or break down a user story, requirement, build spec, technical specification, or epic, **load and follow** the `user-story-architect` skill (Life Sciences Cloud → `lsc-user-story-architect`).

Hard blockers:

- Concrete business persona — never "user" / "business user" / "developer".
- Given / When / Then in **business language** for behavioural ACs (no Apex class names, IP versions, SOQL, or API field names inside Pattern A).
- A `## Technical Implementation (high-level)` section **after** the ACs.
- Never invent OmniScript / DataRaptor / IP / Apex names — verify with `code-review-graph` first.
- Ask clarifying questions as a numbered list in Copilot Chat **before** writing the story. Wait for answers.
